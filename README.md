# 下班倒计时 · 桌面挂件

一个会隐身的 Windows 桌面挂件：下班倒计时 + 摸鱼赚得 + 假期/发薪日倒计时。

> 鼠标移上去亮起来，移开自动隐身，不占地方也不碍眼。

![首页](assets/widget-dark.png)

## 功能

- **下班倒计时** — 时/分/秒实时倒数 + 今日进度条，到点自动切金色庆祝态
- **摸鱼赚得** — 按秒算钱：月薪 ÷ 出勤天数 ÷ 当日工时，金额一分一分往上跳
- **假期倒计时** — 内置中国大陆 / 中国香港两套日历，可切换
- **发薪日倒计时** — 设好每月几号，六种可爱说法随机轮换
- **白天 / 黑夜模式** — 白色壁纸上切换浅色底，才真正隐身
- **高度可调** — 隐身亮度 0–100%、挂件大小 50–200%、自定义称呼、作息制度

## 下载

前往 [Releases](../../releases) 下载最新安装包。

Windows · 约 60MB · **无需安装 Python**（打包时已内置运行环境）。

首次打开会有 Windows 蓝色警告（未付费签名），点「更多信息」→「仍要运行」即可。
