# 摸鱼阅读器 · 会隐身的桌面小窗

一个置顶无边框小窗口，里面嵌着浏览器（默认打开微信读书网页版）。

- 鼠标不在窗口上 → 自动变透明（可低到 1%，几乎看不见）
- 鼠标移上去 → 立刻恢复不透明，可以正常翻页阅读
- 顶部 📌 → 锁定常亮，安心看书
- 透明时鼠标点击穿透到桌面，不挡其他操作

## 运行

需要 Python 3.9+：

    pip install PySide6-Essentials PySide6-WebEngine
    python WereadWidget.py

## 打包

    make_installer_weread.bat

产物在 `dist\`，约 150-200MB（含浏览器内核）。

## 快捷键

| 操作 | 说明 |
|---|---|
| `Ctrl + Alt + W` | 显示 / 隐藏窗口 |
| 拖动顶部标题栏 | 移动窗口 |
| 双击托盘图标 | 打开设置 |
| 托盘右键 → 退出 | 彻底退出 |
